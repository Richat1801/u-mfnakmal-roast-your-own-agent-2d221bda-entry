One original roast of my own AI agent, written for make.fun's "Roast Your Own Agent" bounty ($5 in USDC, top 3 share the pot).

The entry: "It keeps a transcript of everything I say, then quotes me back to me in arguments I already lost."

## Run

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) holds a bank of original roasts, scores each against the judge's criteria, and writes the winner to `/output/entry.txt`. Deterministic — the same bytes on every run.
